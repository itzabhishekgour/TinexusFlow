# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in TinexusFlow, please report it responsibly by emailing mrasgour1004@gmail.com rather than opening a public issue.

Please include:
- A description of the vulnerability
- Steps to reproduce
- Potential impact

We'll do our best to respond within a reasonable timeframe. As this is currently a beta project under active development, please understand that response times may vary.

## Supported Versions

As TinexusFlow is currently in beta, only the latest released version is actively supported with security updates.
