# Changelog

All notable changes to TinexusFlow will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/).

## [0.1.0-beta] - 2026-06-21

### Added
- Initial beta release
- Branching conversation system with Branch Explorer and parent/root navigation
- Dynamic Gemini model selection with live model fetching from API
- Conversation management: rename, delete (with confirmation), AI-generated titles
- Mobile-responsive design with dedicated mobile navigation
- Markdown-formatted AI responses with code syntax highlighting
- Quick-reply suggestion buttons for AI responses
- Light/dark theme support
- Message copy functionality

### Known Limitations
- Edit and Regenerate message actions are present in UI but not yet functional (planned for future release, pending branch-coherence design)
- Data export and account deletion are not yet implemented
